3 · 小怪兽跳过来：Agent 那边有事要你看，它的头像从“Agent”跳到“我的”

什么时候播：Agent 刚把一件事交给你（卡住、做完待验收、PR 待审），而你还没看到过。你回到 App（窗口激活）或者点开侧边栏时播一次，一件事只播一次。怎么跳：交事的那个 Agent 的头像从“Agent”那行蹲一下、弧线跳起、落在“我的”那行，落地时压扁一下再弹回，角标 +1；一共约 0.9 秒。同时有几件，几个头像间隔 120 毫秒依次跳，最多 3 个。性能：只在这 0.9 秒里逐帧重画一个小图层，不重建页面；系统开了“减少动态效果”就不跳，角标直接淡入。

6 · 设置 · Agent：给装好的 Agent 一键安装 adhd-todo 的 MCP
在这台 Mac 上找到的 Agent
“安装 MCP”就是把 adhd-todo 的 MCP 服务装进这个 Agent。装好后它干活时会自动把进度汇报到这里；不会安装或启动 Agent 本身。
没找到你的 Agent？任何支持 MCP 的工具都能接：命令是 ~/.local/bin/adhd-core mcp 复制

App 检查这台 Mac 上装了哪些 Agent（命令在不在 PATH、配置文件夹在不在），装了的显示“安装 MCP”。有官方命令的（Claude Code、Codex、Gemini CLI、Qwen Code、Kimi CLI、Amp）直接替你跑那条命令；只有配置文件的（Cursor、opencode、Windsurf、Zed）先备份原文件再加一项。装好的显示汇报情况。新增 opencode、Copilot 两个像素头像，其他没专门画的用按名字着色的小机器人。
