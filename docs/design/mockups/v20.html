v20 · 多选和批量操作（#75）

所有任务列表都能多选：标题右边的「选择」按钮进入选择模式，或者直接 ⌘ 点击、⇧ 点击、⇧↑↓。选中两件以上时，列表底部浮出一条像素面板，放批量操作：完成、移到…、优先级、交给 Agent、删除。右键菜单对选中的几件生效。项目页里还能把选中的几件一起拖到 Agent 托盘：小人扛着一摞卡片，放下后提示条可以「复制给 Agent」。

三 · 规则

  • 在哪能选：我的、项目页（列表、两栏、看板卡片）、收件箱、Agent 页、已完成、搜索结果。日历和总结不选。
  • 怎么选：⌘ 点击加一件或去掉一件；⇧ 点击从上次点的那行连到这一行；⇧↑↓ 从当前行往上或往下扩；⌘A 选中当前页所有能选的行；Esc 先清选择（再按才走原来的 Esc 顺序）。普通点击照旧：打开检查器，并把选择换成这一行。
  • 「选择」按钮：每个能多选的列表，页面标题右边有一个「选择」（像素勾选框图标）。点了进入选择模式：每行最左边的状态圆圈换成勾选框，点一行就是勾上或取消，不再打开检查器；标题行变成「已选 3 件 · 全选 · 完成」。批量面板在选中 1 件时就出现。点「完成」、按 Esc，或批量操作做完后，退出选择模式。不进入模式时，⌘ 点击和 ⇧ 点击照样能用（面板要选中 2 件才出现）。第一次在一个列表里 ⌘ 点击时，「选择」按钮闪一下，告诉人这里有这个按钮。
  • 选中的样子：`bg.selected` 底，相邻选中行连成一块；键盘焦点那一行多一道 accent 细边。
  • 批量面板：选中 2 件及以上才出现，浮在列表底部中间，像素面板（日卡的形状：两级台阶圆角、2 pt 实边、4 pt 硬阴影）。从左到右：`3 件`、完成、移到…、优先级、交给 Agent、删除、×（清选择）。窄窗口放不下时，文字按钮变成只剩图标，件数和 × 总在。
  • 每个操作：完成（⌘↵）、移到…（项目或收件箱）、优先级（P0–P3）、交给 Agent（⌘⇧A，只对你自己没做完的任务，别的跳过并在提示里说）、删除（确认框说「删除 3 件任务？」）。都是一次操作，一次撤销（⌘Z 或提示条的「撤销」）。
  • 右键菜单：在选中的行上右键，菜单顶上写「3 件任务」，项和批量面板一样；在没选中的行上右键，只对那一行，选择不变。
  • 拖一摞（项目页）：拖选中的任一行，带上全部选中的，按列表里的顺序；小人扛着一摞，最多叠 3 张，右上角圆标写件数。拖一行没选中的，只带它自己。看板里拖选中的卡片到别的泳道，全部改状态。
  • 放下：几行一起离开「我的」栏，按原顺序出现在「等 Agent 接手」，各带 8 % 的 accent 底，2 秒淡掉；托盘的机器人每接一件跳一下，间隔 120 ms。
  • 提示条：`已交给 Agent：3 件` · **复制给 Agent** · **撤销**。复制的是 `Do adhd-todo tasks #12, #13 and #14.`；一件时 `Do adhd-todo task #12.`。单件拖过去也有这个按钮。复制后按钮文字变成「已复制」1.5 秒。
  • 完成的行：已完成、已取消的行可以选（为了批量删或重新打开），但「交给 Agent」跳过它们。
  • 无障碍：选中的行读出「已选中」；批量面板是一个工具栏，Tab 能进。
