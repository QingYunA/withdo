Linear 收件箱

清空后只放一张淡色插画和一句「You're all caught up」，没有按钮。空是好事，就让它安静。

Cursor 后台 Agent 面板

没有运行中的 Agent 时，一句说明加一个「New agent」按钮：空状态顺手教你怎么开始。
