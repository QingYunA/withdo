v30 · Android 任务菜单
桌面任务菜单（ui-spec「Task menu」）搬到手机：长按任务行，或在任务页点 ⋯，从底部弹出。412 × 915 dp，① – ⑤ 浅色，⑥ 深色。

同类应用怎么做

  • Todoist：右滑完成、左滑改日期；任务详情里用底部弹出的菜单改属性。
  • TickTick：长按拖动排序，左滑露出操作按钮；详情页右上角有 ⋯ 菜单。
  • Google Tasks / Material 3：手机上的上下文操作用 modal bottom sheet，不用桌面式弹出菜单。
  • 我们取：长按 → 底部菜单；任务页 ⋯；内容和桌面任务菜单一一对应。

菜单（和桌面任务菜单同一套）

  • 顶部是任务标题和 #编号 · 项目，下面是状态条（7 个图标，每格 52 dp 高）和优先级条（P0–P3）。点一下就生效并关闭菜单，同时轻震一下。
  • 行高 52 dp：分类 / 移到… / 提醒我… 右边显示当前值和 ›，点开后在同一个弹层里换页，左上角 ‹ 返回。
  • Agent 的任务有 PR 时多一行「打开 PR」。桌面的「打开方式…」和「询问这个任务…」手机上没有。
  • 分类页和移到…页长得一样：筛选框、列表、当前项打勾、「无」放在最后。手机上不能新建分类。

打开方式和手势

  • 长按任意任务行（我的、Agent、项目页、搜索）：行变成选中色，手指抬起时弹出菜单。下一步做拖拽排序时，长按后移动手指就开始拖动，不弹菜单。
  • 任务页：⋯ 打开整个菜单；点状态 / 分类 / 项目 / 提醒那一行，直接打开对应那一页；优先级条照旧，点了就改。
  • 删除不再确认：菜单关闭，底部出现「已删除「标题」 撤销」，6 秒后消失。撤销会把任务原样放回，编号也不变。
  • 下滑或点遮罩关闭菜单；系统返回键在子页面先回到主页面，再按一次关闭菜单。
