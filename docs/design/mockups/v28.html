v28 · Windows 托盘与菜单
只在 Windows 上有托盘（2026-10-20 决定）：Windows 没有 Dock，关掉窗口后从托盘或再次启动找回。macOS 仍然没有托盘。

托盘图标

  • 应用图标在 12×12 网格上的像素版：深色方块 #1E293B，白色对勾 #F8FAFC，四角各缺一格。
  • 文件 app/theme/sprites/tray.png（1x），代码放大 2 倍给出 24×24：150% 缩放时一格是 2 个像素，100% 和 200% 由系统缩放。
  • 悬停提示：ADHD Todo。

行为

  • 左键单击：打开主窗口（隐藏或最小化时都调出来）。
  • 右键单击：菜单 打开 ADHD Todo / 设置… / 退出。
  • 关窗口：窗口隐藏，提醒、日终总结和 PR 通知照常在后台。
  • 再次启动：不开第二个进程，调出已有的窗口（双平台单实例）。

菜单栏

  • Windows 的 File 菜单：设置…（Ctrl+,）、分隔线、退出。macOS 的应用菜单不变。
  • 界面上的快捷键提示在 Windows 写成 Ctrl+K、Ctrl+F、Ctrl+Shift+A、Ctrl+Enter、Ctrl+Backspace。
