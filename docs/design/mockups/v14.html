v14 · 日报和周报（#67）

把今天（或这一周）做完的事按「你」和每个 agent 分组列出来，能一键导出成 Markdown 拿去发日报、周报。第一步不用模型：数据全来自已完成的任务和 agent 的汇报，所以又快又准；第二步再加「让助手写成一段话」。

一 · 日报

侧边栏「已完成」下面多一行「总结」，默认打开今天。

二 · 周报

切到「本周」：上面一排像素柱子是每天做完几件（一块是一件，颜色分人），下面同样按人分组，组里按天排。

三 · 导出 Markdown，以及规则

点右上角「导出 Markdown」弹出预览：可以复制，也可以存成 .md 文件。内容和页面上看到的一样。

规则
  • 谁做完的：沿用「今天做完」现在的判断。任务完成时（前后 5 秒内）有 agent 汇报就算那个 agent，否则算你。PR 合并后自动完成的，算发起 PR 的 agent。
  • 每件事一行：标题、项目、PR 号；agent 做的再带它最后一句汇报，只取一行。
  • 时间范围：按本地时间。日报是当天 0 点到 24 点；周报是一整周，周一开始（跟随系统设置的每周第一天）。
  • 只算已完成，取消的不算。
  • 还在做的：页面底部一行「3 件进行中，1 件卡住」，点进 Agent 页；导出时也写进去。
  • 没有事情的日子：页面写「这天还没有做完的事」，导出按钮变灰。
  • 往前翻：‹ › 按天或按周翻，到今天（本周）为止。
