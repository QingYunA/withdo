v14 · Agent 页：本机已有 / 更多

现在十款 harness 平铺两列，装了的和没装的交错，第一眼要逐个分辨哪一行能点。这一版分成两组：本机已有只放这台 Mac 上找得到的，保留汇报次数和「安装 MCP」；更多放还没装的，只给名字和「去下载 ↗」。同时把 DeepSeek Harness、Amp、Kiro、Cline 加进目录。两段都在第一屏；下面「去看看时打开」和终端命令照旧，往下滚才出现。

1浅色 · 中文：本机已有 6，更多 8

本机已有的六行保留原有信息：汇报次数、找到的路径、MCP 已安装或安装按钮。更多只留名字和去下载，不再重复「这台 Mac 上没有」。DeepSeek Harness 用应用图标里那只黑鲸鱼，画成 12×12 像素头像；深色模式自动反白，否则看不见。其他新 harness 先用按名字着色的机器人。

2深色 · 英文：On this Mac / More

英文沿用现有的 MCP installed / Install MCP / Get it ↗，组名用 On this Mac / More。

怎么分

组谁进来每行给什么
本机已有 命令在 PATH、配置目录或文件在、或汇报过，任一成立。 头像、名字、汇报次数或 找到了 · 路径；右侧是 ✓ MCP 已安装 或「安装 MCP」按钮。
更多 目录里其余的 harness，也就是这台 Mac 上没找到的。 头像、名字、去下载 ↗；两列紧凑排，不写状态行。

这一版加进来的 harness

  • DeepSeek Harness：本机有 ~/.dsh，但 PATH 里没有 dsh 命令，检测靠配置目录。它的 MCP 不是 JSON 配置，而是 Cordis 补丁（~/.dsh/cordis.patch.yml 或 profile 里的 patch），所以「安装 MCP」要新写一个 YAML 分支；YAML 写不了就落到现有的手动片段。
  • Amp、Kiro、Cline：各查一次配置位置和安装方式。查不到自动安装的，先只进「更多」或给手动接入，不硬塞一个会失败的按钮。

几个决定

  • 顺序仍按目录，不按汇报次数重排：行不会跳，肌肉记忆还在。
  • 「更多」不折叠：一眼能看到还有哪些；等一屏放不下再考虑折成一行。
  • 汇报过的也算「本机已有」，即使这次没扫描到：装了 MCP 但临时找不到命令的 agent 不消失。
  • 组头带数量（6 / 8）：清单再长，也知道自己漏没漏。
  • 一个都没找到时，「本机已有」留一行空状态：「还没在这台 Mac 上找到 Agent」，「更多」照常。空状态也带「去看看怎么接」的链接。
