v29 · 应用内登录（设置 › 同步、手机同步页）
替换 v27 ① 和 v27「正在登录」：不再打开浏览器，账号和密码直接在卡片里填。其余状态（已同步、上传、失败、两边都有数据）不变。输入框沿用「助手」页的 fieldWell。

原则

  • 登录全程在应用里完成，不打开浏览器，也不跳出 App。
  • 只有登录，没有注册和找回密码：账号由服务器管理员在 Zitadel 里建。
  • 密码不保存；登录后只在钥匙串（手机上是 Keystore）里存 refresh token。

交互

  • 两个框都有内容，按钮才可点；在密码框按回车（手机上按「完成」）等于点按钮。
  • 打开页面时焦点在账号框；账号框按回车（手机「下一项」）跳到密码框。
  • 正在登录时两个框和按钮都禁用，按钮文字换成「正在登录…」。

出错

  • 错误显示在按钮下面一行，用 blocked 红：账号或密码不对 / 试的次数太多了，过几分钟再试 / 这个账号开了两步验证，应用内登录暂时不支持 / 账号已停用，请联系管理员 / 网络错误沿用现有句子。
  • 账号或密码不对时清空密码框并把焦点放回去，账号保留。
