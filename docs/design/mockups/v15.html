v15 · 日报周报的三种画法（#67）

在 v14b 的基础上加两样东西：顶上一条像素小场景，把「做完一件事」画出来；场景下面是助手写的两三句话。场景有三种画法：砌砖、出货、上架，下面都画了日报和周报，方便对比。点任意一个窗口可以重播动画。

先并排看三条场景（日报）

一 · 砌砖：一件事一块砖

日报：今天做完的事一块块落下来，砌成一小截墙，砖的颜色是谁做的。周报：每天一段，连成这一周的墙，没做事的那天就是平地。

二 · 出货：一件事一个包裹（Stardew 收工结算）

日报：每个人把自己做完的包裹抛进出货箱，包裹上的绳子是这个人的颜色。下面是结算单，一行一个人，依次亮起、数字往上跳，点一行展开那个人做完的事。周报：一天一个箱子，周末的箱子盖着。

三 · 上架：一件事一本书

日报：做完的事一本本插上书架，书脊的颜色是谁做的，合并了 PR 的书有一道金边，书的高矮跟着标题长短变。周报：一整排书架，每天之间用书挡隔开。

规则
  • 助手写什么：只用这段时间做完的任务、它们的汇报和 PR 标题，看不到代码。日报 2～3 句，周报 3～5 句。说你和 agent 做了什么，不打鸡血、不说教，不编没有的事。
  • 什么时候写：第一次打开这一天（这一周）时写一次，存进库里，之后再打开直接显示，不再花钱。右上角「重写」再写一次。今天（本周）还没过完，有新做完的事时，「重写」旁边多一个小点提示。
  • 用哪个模型：设置里助手用的模型，头像跟着模型的 logo（#63）。没配模型时这一段不显示，其余照常。
  • 出字：一个字一个字出来，每 30 ms 一个字，后面跟一个闪烁的方块光标，写完光标消失。已经存下的那段直接整段显示。
  • 导出 Markdown：这段话放在最前面，下面是清单。
  • 场景动画：一帧 100 ms，一件事落下用 5 帧，相邻两件隔 350 ms（周报 120 ms）。打开页面播一次，之后静止；点场景重播。系统开了「减弱动态效果」时直接画最终的样子。
  • 场景的天色：跟着打开时的本地时间，白天、黄昏、夜里三种。看过去的日子用那天收工时的天色（黄昏）。
  • 彩蛋（以后再说）：合并了 PR 的日子，偶尔有只螃蟹从场景里走过去。
  • 收工提醒：每个工作日到点提醒一次，点开是今天的日报；周五换成周报。窗口正停在「总结」上时不提醒。今天一件没做完也提醒，只是换句话，不提「0 件」。
  • 不做：连续打卡、没做完的事标红、分享卡（以后再说）。
