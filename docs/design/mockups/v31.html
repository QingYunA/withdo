v31 · 输入框优先：让 Agent 帮你管待办
不砍功能，换入口。打开 App 第一眼就是一个大输入框：打字或按住说话，说一句，Agent 把它拆成任务、认出日期和分类、该交给 Agent 的直接交出去。所有面板都是「现在 → 提案」对照；决定已写进 ui-spec 的 Input first (v31)。

原则

  • 一个入口：首页顶部的大输入框，和菜单栏弹层是同一个框。其余页面不再各自挂 Composer。
  • 不用填表：日期、分类、项目、重要、交给谁，都由 Agent 从一句话里认出来，认错了点芯片改。
  • 直接生效 + 撤销：不弹预览确认；新任务带着认出的芯片落进列表，底部一条撤销。

已确认

  • 理解能力来自官方服务（Google / 邮箱登录，Free 与付费阶梯）；自带 key 留在「高级」。
  • 语音只用系统语音转文字，mac / Windows / Android，将来 iOS。
  • 自己的任务只有 待办 / 进行中 / 完成；P0–P3 → 一颗「重要」星；Branch / PR / 动态 只给 Agent 任务。

拿掉的入口去了哪里

  • 收件箱 → 并进「今天」。没项目的任务按日期落在 今天 / 之后；Things 的 Inbox 是「还没决定的」，我们让 Agent 替你决定，就不需要这一层。
  • 分类子行（工作 / 生活） → 任务上的彩色芯片；点芯片 = 只看这个分类（顶部出一个可关掉的筛选条）。
  • Agent 子行 → Agents 页里按 Agent 分组，侧栏不再展开。
  • 已完成 → 每个列表底部「今天完成」可展开看全部历史；也能搜。Todoist 把它藏在菜单里，Things 叫 Logbook。
  • 总结 → 「今天完成」右侧的「看看今天 ›」进入出货场景；收工提醒的通知也直接打开它。像素场景保留，是完成时的那颗「小番茄」。
  • 最近变更 → 默认已经关着，移到 设置 › 高级。
  • 里程碑、看板 → 留在项目页里，不进侧栏。

为什么是菜单栏

  • Things 的 Quick Entry、Todoist 的菜单栏 Ramble 都证明了：记录要发生在「想到的那一刻」，不能先切回 App。
  • 弹层和首页是同一个输入框、同一套回执与撤销，用户只学一次。
  • 「今天」最多列 5 件，点行就在主窗口里打开详情；不在弹层里编辑。
  • 底部一行 Agent 状态：卡住的数字用 blocked 红，是这里唯一的强色。
  • Windows 用现有托盘（app/tray.go），左键改为弹出同样的面板；macOS 用 mygo 已有的 NewTray（NSStatusItem）+ NewFlyout 的 Popover 锚定在图标下；全局快捷键用 GlobalShortcut.Register。
技术备注给下一轮实现计划用

语音：系统语音转文字

  • macOS / iOS：SFSpeechRecognizer（可设备端识别，免费）
  • Windows：Windows.Media.SpeechRecognition
  • Android：SpeechRecognizer
  • mygo（v0.5.1 / v0.6.0）都没有语音接口，只有网页用的麦克风权限：先做一次 spike，cgo / objc + WinRT 绑定，或给 mygo 提 PR。
  • 转出的文字走和打字完全相同的路径，不做 TTS。

理解：官方服务 + 本地兜底

  • 现有链路：Composer → internal/agent（Eino）→ 回执 + 撤销，基本不动。
  • provider 增加「官方」一项，登录后默认用它；界面不再让用户挑厂商。
  • 未登录：本地规则认日期、#分类、! 重要、用「，还有」拆句，直接建任务。
  • 官方服务的 Google / 邮箱登录要换掉现在 Zitadel 账号密码（v29）的那一套。

改动面（按 PR 拆）

  • 首页大输入框；项目页保留小输入框，其它页面去掉 Composer
  • 属性简化：三态状态、星标、Inspector 按来源分两种
  • 侧栏合并：收件箱 / 已完成 / 总结 / 分类子行
  • 设置重组：账号 / 通用 / Agent / 高级
  • 菜单栏弹层 + 全局快捷键
  • 语音 spike；官方服务登录
