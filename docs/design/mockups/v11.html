v11 · 服务商 logo 像素化（#63）

输入框模型 chip、模型菜单、设置里的服务商 logo 现在是官方彩色矢量图，侧边栏的 agent 是像素 sprite，同一个界面里有两种画法。第二版不再手画：把每家的官方 SVG 按 18×18 的格子取样，一格被 logo 盖住一半以上就点亮，颜色取官方的颜色，所以形状和颜色都是原样，只是边变成了像素。单色的（OpenAI、Kimi、Ollama）深色模式下自动变浅。Anthropic 用侧边栏 Claude Code 的螃蟹。顺带把检查器里的文本符号「✦」换成像素 sparkle 图标。

一 · 10 家服务商：官方 → 像素

每行：官方 logo、像素版放大（浅底和深底各一个），以及实际 18 pt 的大小。

二 · 放进界面

左：输入框和模型菜单。右：检查器打开时的窄框（chip 只剩 logo），以及和侧边栏 agent 头像并排时的样子。

三 · 尺寸

官方形状在 12×12 里保不住（上一版好几个认不出来），所以服务商 logo 是 Pixel language 里唯一用 18×18 格子的图：一格画成 1 pt 或 2 pt，只用 18 pt 和 36 pt 两种大小。

输入框 chip、模型菜单16 pt 矢量 → 18 pt（一格 1 pt）
设置：服务商列表的行28 pt 矢量 → 18 pt
设置：当前服务商、服务商格子38 / 32 pt 矢量 → 36 pt（一格 2 pt）

四 · 「✦」换成像素 sparkle

检查器里助手刚改过的值后面有个小标记，现在是文本符号「✦」，违反 Pixel language「不拿文本符号当图标」。换成已有的像素 sparkle 图标（IconSparkle，12 pt）。
