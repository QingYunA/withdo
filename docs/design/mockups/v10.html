v10 · 收下：动画，以及项目页的入口

PR 2 的两件事：一、点「收下」以后，这一行怎么离开（#69）；二、项目页里待审查的 agent 任务，鼠标悬停时露出「收下」（#70）。按 Pixel language：按钮里的勾是像素画，逐帧画出来；行的收起、下面的行上移、进入「今天做完」是布局动画，保持平滑。每块右上角可以播放和慢放 10 倍，框里的「收下」也能直接点。

一 · 点「收下」之后（#69）

「我的」页顶部：Agent 交过来的两件事，下面是「今天」和「今天做完」。点「收下」之后，注意看三处：按钮、这一行、下面的行。

二 · 项目页：悬停露出「收下」（#70）

项目页右边的 Agent 栏。平时一行和现在一模一样；鼠标移上去（或键盘选中）时，右边的时间换成按钮：有 PR 的是「打开 PR」+「收下」，没有 PR 的是「去看看」+「收下」，和「我的」页一致。右边一块可以真的把鼠标移上去、点「收下」。

三 · 看板卡片（#70）

看板里待审查的卡片也一样：悬停时卡片底部右边的时间换成按钮。拖到「已完成」那一列照旧可以完成。
