# Android captures

`mine-light.png` and `mine-dark.png` were captured from the installed Android APK on a Pixel 6 / API 35 emulator. The fixture task was created by Maestro in airplane mode and retained after the app process restarted; it is test data, not seeded application content.

Application source: `7a3b05c73c33bda969623b80797eb06b791ac97e`. [Build](https://github.com/QingYunA/adhd-todo/actions/runs/38852900815) and [capture / source-equivalence verification](https://github.com/QingYunA/adhd-todo/actions/runs/38856926109). Both modes passed the scoped Mine visual review. Other routes, enlarged text, Chinese IME, tablet layouts and physical-device notifications are not represented by these images.
